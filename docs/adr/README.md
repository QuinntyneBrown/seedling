# Architecture decision records

One file per decision, `ADR-NNN-kebab-title.md`, numbered in order and never renumbered. A
superseded ADR stays and says what superseded it. Read the ADRs covering an area before changing
it; write one for any decision that changes the architecture (a dependency, a layer boundary, a
hosting choice, a testing policy, a data ownership rule).

Use [ADR-000-template.md](ADR-000-template.md).
