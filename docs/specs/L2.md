# L2 - Detailed Requirements

> Each L2 traces to one or more L1 requirements in `L1.md`. Acceptance criteria use Given/When/Then
> so they translate directly to tests. Every acceptance test in this repository shall carry a
> `Traces to: L2-NNN` header comment.

---

## L2-001: The API answers a smoke request
**Traces to:** L1-006

The system shall expose `GET /api/_ping`, anonymous, so the deploy pipeline and the test suite can
prove the API is up.

**Acceptance Criteria:**
1. Given the API is running, when `GET /api/_ping` is sent without a session, then the response
   status shall be 200 and the body shall contain `status: "ok"`.

---

## L2-002: Every screen has a main landmark reachable from a skip link
**Traces to:** L1-002

The application shell shall render one `<main id="main">` per screen and a "Skip to content" link
that targets it as the first focusable element.

**Acceptance Criteria:**
1. Given any screen, when it has rendered, then exactly one `main#main` shall be present.
2. Given any screen, when the keyboard focus enters the page, then the first focusable element
   shall be the "Skip to content" link with `href="#main"`.
