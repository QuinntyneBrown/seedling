# Colors

Alias colour tokens, painted with the live custom properties the app loads. Each is named for its role.

## Brand ramp

<div className="sb-unstyled" style={{ display: 'flex', flexWrap: 'wrap', gap: 8 }}>

    </div>
  ))}
